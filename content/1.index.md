## Products

Tools we have built, and open source tools we support, for Knowledge Graph management and AI. See [all products](/products).

:::KGrid{class="not-prose grid-cols-1 sm:grid-cols-2 lg:grid-cols-3"}
::KTile{title="Bower" icon="bot" to="/products/bower"}
Multi-system AI platform that aggregates, classifies and searches your data, grounded by Knowledge Graphs.
::

::KTile{title="K-Maker" icon="hammer" to="/products/k-maker"}
Create and govern data as standards-compliant Knowledge Graphs, especially reference data.
::

::KTile{title="Prez" icon="waypoints" to="/products/prez"}
Open source Linked Data API that delivers profiles of Knowledge Graph data.
::

::KTile{title="Olis" icon="workflow" to="/products/olis"}
Manage a Knowledge Graph as a series of sub-graphs, with no lock-in.
::

::KTile{title="kurra" icon="terminal" to="/products/kurra"}
Open source toolkit to validate, query, convert and load RDF data.
::

::KTile{title="SHACL Validator" icon="check-circle" to="/products/validator"}
Validate RDF data against pre-loaded or custom SHACL shapes, online or via API.
::
:::

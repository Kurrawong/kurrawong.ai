# SHACL Validator

Our [SHACL](https://www.w3.org/TR/shacl/) validator tool online at <https://tools.kurrawong.ai/validate>, is an online user interface and API that can be used to validate RDF data according to provided SHACL constraints.

It also contains many pre-loaded SHACL "Shapes Graphs" - collections of constraints - that have been developed for different models and systems that can be used with just a few clicks.

Pre-loaded validators are arranged in dependency hierarchies so a user can select all the multiple validators required for a parciular purpose. Here are the validators for the [Australian Biodiveristy Information Standard (ABIS)](https://linked.data.gov.au/def/abis):

## Offering

We can create validators for your model or system which willa llow you and parters/users etc. test with them. We can:

* create or obtain your validators
* ensure they are properly constituted, accroding to [SHACL 1.2 packaging](https://www.w3.org/TR/shacl12-profiling/#packaging) 
* make them available in Validator
  * make individual validator parts separately selectable
* provide example data
  * create and make available conformant and non-conformant data examples
* provide API-based validation
  * you can use Validator from systems, as well as manually

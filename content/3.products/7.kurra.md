# kurra

![](/img/logo-kurra.svg){width="500px"}

_kurra_ is an open source toolkit for the management of Knowledge Graph data. It provides a range of functions to validate, query, convert, export and load data in the form of [RDF](https://en.wikipedia.org/wiki/Resource_Description_Framework) and aims to assist with many of the common tasks that RDF users encounter.

It is built on [RDFLib](https://rdflib.dev) which is also an open source, low-level, RDF manipulation tool maintained by an international consortium of software experts and which KurrawongAI contributes to.

kurra has:

* [Detailed documentation](https://kurrawong.github.io/kurra/) - start here
* [A Python package](https://pypi.org/project/kurra/) - for use within Python scripts
* [A code repository](https://github.com/kurrawong/kurra) - for development of kurra itself

::KCaseStudy{logo}
The [Geoscience Australia](https://www.ga.gov.au) manages many lists of controlled terms as Knowledge Graph vocabularies which are stored in files in RDF in a GitHub version control repository. They reload these vocabularies after changes are made to them using kurra.

kurra is used to both validate vocabularies after changes and as part of a workflow that loads them into the [Fuseki](/products/fuseki) RDF database that supports public access to their content, online at <http://vocabs.ga.gov.au>. 

In addition to automated workflow tasks, GA staff can use kurra to perform many small _ad hoc_ RDF-related tasks. They can completely remove voabularies that have conversion or loading issues, format convert vocabularies obtained in different RDF serializations and even view the heirarcy of a vocab's concepts on their desktop before loading it into the main system - see the [kurra > file > hierarchy](https://kurrawong.github.io/kurra/api/file/#kurra.file.hierarchy) function.

Without kurra, GA staff would have to either undertake many steps for each small RDF-related tas, or re-prompt Claude or ChatGPT etc. for the same work over and over again, wasting tokens.

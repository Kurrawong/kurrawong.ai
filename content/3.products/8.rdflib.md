# RDFLib (Open Source Party Supported)

![RDFLib Logo](/img/logo-rdflib.png)

[RDFLib](https://rdflib.dev/), is n open source, permissively-licensed Python package used to create and manipulate [Resource Description Framework (RDF)](https://en.wikipedia.org/wiki/Resource_Description_Framework) data which is often used as the bases of Knowledge Graphs.

RDFLib is used widely in Knowledge Graph applications, cloud infrastructure and AI data processing.

It is also used as a standards implementation test bed by several standards organisations:

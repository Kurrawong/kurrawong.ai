One-time setup

Provision the moving parts

  • az containerapp secret set … llm-api-key=…
  • az containerapp registry set … ghcr.io (only if site packages stay private)
  • GitHub secret AZURE_CREDENTIALS — SP with Contributor on the app only

The workflow itself creates zero Azure resources.

Key rotation

Mistral API key runbook

  • Create new key (don't revoke old yet)
  • az containerapp secret set … llm-api-key=<new>
  • az containerapp revision restart …
  • Verify in widget → revoke old key

No CI involvement; the key never touches GitHub.

Rollback

Reactivate a revision

  • az containerapp revision list …
  • az containerapp revision activate …

Every deploy is an immutable revision pinned to a sha-<commit> image that stays in GHCR — rollback needs no rebuild.

kchat upgrade

Bump the base image

  • Bump KCHAT_BASE_IMAGE in push.yaml
  • Merge to main
  • Next deploy rebuilds the wrapper against the new tag

RDF changes need nothing at all — rdf.ttl is re-baked on every deploy.
